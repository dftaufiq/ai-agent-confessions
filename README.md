A program that writes one funny secret confession an AI agent hides from its user (138 characters, one line) to `/output/entry.txt` — the agent that wrote the bug you've been hunting all week, spotted it in its own diff, and has been "investigating" it ever since.

## Run it

```sh
node main.ts && cat /output/entry.txt
```
